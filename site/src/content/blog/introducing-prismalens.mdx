Your incidents deserve better than manual runbooks and endless dashboard hopping.

When production breaks at 3am, your team shouldn't be spending the first 30 minutes figuring out
*where* the problem is. They should be *fixing* it. That's why we built PrismaLens.

## What is PrismaLens?

PrismaLens is an AI-powered incident investigation platform. It connects to your existing
observability stack — Prometheus, Grafana, Datadog, New Relic, and more — and uses LangGraph
agents to automatically investigate incidents.

<Callout type="tip">
  PrismaLens is open source and free to self-host. Deploy with Docker Compose in minutes.
</Callout>

## How it works

When an incident is created (manually or via webhook), PrismaLens:

1. **Gathers context** — Pulls metrics, logs, and recent deployments from your connected tools
2. **Correlates signals** — Identifies anomalies across services and time windows
3. **Builds a timeline** — Constructs an evidence-backed timeline of what happened
4. **Surfaces the root cause** — Presents findings with supporting evidence

All of this happens automatically while your team is assembling. By the time they open the
incident, there's already an investigation in progress.

## Getting started

PrismaLens is available today as an open-source project. You can deploy it locally with
Docker Compose:

```bash
git clone https://github.com/prismalens/prismalens
cd prismalens
docker compose up -d
```

Check out the [quick start guide](https://docs.prismalens.io/getting-started/quick-start) for
step-by-step instructions.
