## Commands

`pl` and `prismalens` are the same command. `pl <command> --help` lists each
command's flags.

| Command | What it does |
| --- | --- |
| `pl up` | Starts PrismaLens on `http://localhost:6473` and prints a one-time sign-in link. |
| `pl doctor` | Checks this machine: Node, the workspace, git, the webhook URL and the port. |
| `pl pair` | Prints a one-time link for a browser on another device. |
| `pl service` | Runs PrismaLens in the background on Linux and macOS (`install`, `status`, `restart`, `uninstall`). |
| `pl upgrade` | Upgrades the way you installed. |
| `pl reset` | Deletes the workspace: database, secrets, logs and runs. |

## Environment variables

| Variable | What it does |
| --- | --- |
| `PRISMALENS_HARNESS` | Pins a coding agent: `opencode`, `claude-code`, `codex`, `gemini` or `deepagents`. |
| `PRISMALENS_TELEMETRY=off` | Turns usage counts off. `DO_NOT_TRACK=1` does too. |
| `PRISMALENS_UPDATE_CHECK=off` | Turns the daily update check off. |
| `PRISMALENS_WORKSPACE_DIR` | Uses another workspace folder, like `--workspace`. |

## Troubleshooting

Start with `pl doctor`. Logs are in `~/.prismalens/logs/`.

**Investigate is off.** No agent can run. Open **Settings → Agent** and add or
fix one.

**The run failed "not signed in".** Some agents check sign-in only when a run
starts. Sign the agent in, or enter its API key in **Add agent**, and run again.

**The service shows a git error.** It is git's own message. Check that
`git clone <the same URL>` works in your terminal. PrismaLens never lets git
prompt for a password.

**A second `pl up` refuses to start.** One PrismaLens runs per workspace. It
names the process holding it, which may be the background service:
`pl service status`.

**Filing a bug.** Include the output of `pl doctor` and `pl --version`, and the
relevant lines from the newest file in `~/.prismalens/logs/`. Open it at
[github.com/prismalens/prismalens/issues](https://github.com/prismalens/prismalens/issues).
