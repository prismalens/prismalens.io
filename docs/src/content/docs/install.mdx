PrismaLens is one command under two names, `pl` and `prismalens`. Install it
one way and stick to that: every copy on a machine shares the workspace
`~/.prismalens`, and an older copy refuses a database a newer one has
upgraded.

## Install

<Tabs syncKey="channel">
<TabItem label="macOS and Linux">

```bash
curl -fsSL https://prismalens.io/install.sh | sh
```

No Node needed: the installer brings its own and checks the download against
the release's `SHA256SUMS`. With a display, it also adds the desktop app: in
`~/Applications` on a Mac with Apple silicon, where Launchpad and Spotlight
find it, and in your app menu on Linux (x64). `--no-desktop` installs the CLI
only, as on a server.

</TabItem>
<TabItem label="npm">

Needs Node.js. `pl doctor` says if yours is too old.

```bash
npm install -g prismalens
```

</TabItem>
<TabItem label="Homebrew">

```bash
brew install prismalens/tap/prismalens
```

The desktop app is a separate cask (Apple silicon). It isn't notarized yet, so
open it once from **System Settings → Privacy & Security → Open Anyway**.

```bash
brew install --cask prismalens/tap/prismalens-app
```

</TabItem>
<TabItem label="Windows (preview)">

WSL2 with the macOS and Linux installer is the supported path. Native Windows
installs and runs, with rough edges. In PowerShell:

```powershell
irm https://prismalens.io/install.ps1 | iex
```

It adds the desktop app and a **PrismaLens** Start menu shortcut too; pass
`-NoDesktop` for the CLI only.

Scoop (preview) works too:

```powershell
scoop bucket add prismalens https://github.com/prismalens/scoop-bucket
scoop install prismalens
scoop install prismalens/prismalens-app   # the desktop app, with a Start menu shortcut
```

</TabItem>
<TabItem label="Desktop app (preview)">

Download the zip for your OS from the
[latest release](https://github.com/prismalens/prismalens/releases/latest).

</TabItem>
</Tabs>

## Keep it running

`pl up` runs until you stop it. On Linux and macOS, `pl service install` runs
it in the background for your user and starts it when you log in. On Windows,
turn on **Start at login** in the desktop app.

## Upgrade

```bash
pl upgrade
```

It upgrades the way you installed, and the desktop app with it when the
installer, Homebrew or Scoop put it there. Your database upgrades itself on the next start
and is backed up first, as `prismalens.db.bak-<time>` in the workspace.

### Stable and nightly

PrismaLens follows the **stable** channel unless you choose otherwise. **Nightly**
is a build of `main` from each night whose checks pass. It comes from npm only:

```bash
npm install -g prismalens@nightly
pl upgrade --channel nightly
```

`pl upgrade --channel stable` (or **Release channel** in Settings → About) goes back
to stable. It doesn't downgrade, because a nightly may already have migrated your
database past the last stable release. It stays on the nightly you run until a
newer stable release ships, then upgrades to it.

## Uninstall

Uninstalling leaves your workspace (`~/.prismalens`). To delete it as well,
stop PrismaLens and run `pl reset` first. If you installed the background service, run
`pl service uninstall` too.

| Installed with | Uninstall |
| --- | --- |
| The installer (macOS, Linux), with its desktop app | `curl -fsSL https://prismalens.io/install.sh \| sh -s -- --uninstall` |
| The installer (Windows), with its desktop app | `& ([scriptblock]::Create((irm https://prismalens.io/install.ps1))) -Uninstall` |
| npm | `npm uninstall -g prismalens` |
| Homebrew | `brew uninstall prismalens`, and `brew uninstall --cask prismalens-app` |
| Scoop | `scoop uninstall prismalens`, and `scoop uninstall prismalens-app` |
| The desktop app | delete the app |
