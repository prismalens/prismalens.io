A run's page has a panel beside the transcript. The details icon in the
header opens it, and its close button or **Esc** closes it. It holds five
tabs: **Summary**, **Files**, **Changes**, **Steps** and **Context**.
Summary, Steps and Context are described on
[Runs and questions](/guides/runs/#run-details). This page covers Files and
Changes, and the panel itself.

Everything in the panel is read-only. It reads the code the run recorded:
each repository at the commit the run started from, out of the folder or
mirror PrismaLens cloned it from. The run's own working copy is gone when the
run ends, so what you see is what the agent was given, not what the folder
holds now.

## Files

**Files** lists what the run touched, as a tree. Each file carries a mark:

| Mark | Meaning |
| --- | --- |
| **Cited** | The report cites it as evidence. |
| **Edited**, **Wrote** | A step changed it in the run's copy. |
| **Read** | A step read it. |

A file the run both read and cited shows **Cited**. The count on the tab is
the number of files.

**All files** switches to the whole repository at the recorded commit. A
folder's contents load when you open it.

Pick a file to read it at that commit. A file opened from a citation or a
**Read** step has the cited lines selected and scrolled into view, and lists
the steps that read it. **Open on code host** opens the same file at the same
commit on GitHub, GitLab or Bitbucket, when the code came from one.

When the panel is wide enough, the tree stays beside the file. When it is
narrow, the file takes the tree's place, and **Back** returns to it and to
the citation or step that opened it.

The open file and the tab are in the page's address, so a link to it opens
the same file, and the browser's back and forward buttons move between the
files you opened.

## Changes

**Changes** shows one comparison the run recorded when it started: two commits
of the run's repository and the diff between them. Its title names each end
for what it is, and how many commits lie between them.

PrismaLens picks the pair before the agent starts, in this order:

| PrismaLens knows | The pair | The title reads |
| --- | --- | --- |
| Two deployment events for the service whose commits are in the run's history | The newest of them, and the one before it | `Deployment v2.14.0 against deployment v2.13.2, 3 commits` |
| A tag on the commit the run started from, and an earlier tag | That tag, and the tag before it | `Tag v2.14.0 against tag v2.13.2, 3 commits` |
| Neither | The commit the run started from, and its parent | `Commit a1b2c3d against its parent` |

Deployment events are the deploys PrismaLens stored for the service, the same
ones the overview lists under [What changed and when](/guides/overview/#what-changed-and-when).
A deployment whose commit is not in the history the run started from is
skipped, and the title never calls a tag a deployment.

A run over several repositories records one pair for each, and a picker
chooses between them.

Pick a file in the list to see its diff. **Split** puts the two sides next to
each other and **Unified** interleaves them. A narrow panel always shows
unified. A binary file is listed without line counts, and a change too large
to draw names its files only.

<Aside>
A run started before this view existed recorded no pair, and Changes says
so. Investigate again to get one.
</Aside>

## Sizing the panel

Drag the panel's edge to resize it, or focus the edge and use the arrow keys.
Double-click the edge to return it to its default width. The width and
whether the panel is open are kept for the next time you open a run.

| Window | The panel |
| --- | --- |
| 1024 px and wider | Beside the transcript, resizable |
| 768 to 1023 px | Floats over the transcript; **Esc** closes it and returns you to the icon |
| A phone | Fills the screen; the close button returns to the run |
