## Prerequisites

Start here: [Render setup page](https://dashboard.render.com/u/settings#api-keys)

1. Go to Render Dashboard → Account Settings → API Keys
2. Click 'Create API Key'
3. Give it a descriptive name like 'PrismaLens'
4. Copy the generated key (starts with rnd_)
