## Prerequisites

Start here: [GitHub setup page](https://github.com/settings/apps/new)

1. Go to GitHub → Settings → Developer settings → GitHub Apps → New GitHub App
2. Set 'GitHub App name' to something like 'PrismaLens - <your org>'
3. Set 'Homepage URL' to your PrismaLens instance URL
4. Under 'Webhook', uncheck 'Active' (PrismaLens does not require webhooks)
5. Under 'Permissions', grant the permissions listed below
6. Under 'Where can this GitHub App be installed?', select 'Only on this account' (or 'Any account' for multi-org)
7. Click 'Create GitHub App'
8. On the App settings page, note down the 'App ID'
9. Scroll down and click 'Generate a private key' — save the downloaded .pem file
10. Go to 'Install App' in the sidebar and install it on the desired organization/account

## Tips

- GitHub Apps have higher rate limits than PATs (5,000 vs 5,000 per hour, but per-installation)
- The private key is sensitive — store it securely and never commit it to version control
- You can restrict the App to specific repositories during installation
