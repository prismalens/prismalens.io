This guide walks you through deploying PrismaLens, completing setup, and running your first AI-powered investigation.

## 1. Deploy

```bash
git clone https://github.com/prismalens/prismalens
cd prismalens
cp .env.example .env
docker compose up -d
```

## 2. Complete Onboarding

Open `http://localhost:3000` and complete the 3-step setup wizard:

1. **Create your account** — Set up the owner/admin account
2. **Configure AI provider** — Add your OpenAI or Anthropic API key
3. **Connect an integration** — (Optional) Connect Prometheus, Grafana, or another source

## 3. Create a Test Incident

Send a test alert via the generic webhook:

```bash
curl -X POST http://localhost:3001/api/webhooks/generic \
  -H "Content-Type: application/json" \
  -d '{
    "title": "High CPU usage on api-gateway",
    "description": "CPU usage exceeded 90% for 5 minutes",
    "severity": "critical",
    "source": "manual-test",
    "service": "api-gateway"
  }'
```

## 4. Watch the Investigation

Navigate to the **Command Center** at `http://localhost:3000`. You'll see:

- A new incident created from your alert
- An AI investigation automatically started
- Real-time progress as the agent gathers evidence
