PrismaLens can be deployed in two ways: **Docker Compose** for production, or **locally** for development and testing.

## Docker Compose (Recommended)

The fastest way to get PrismaLens running in production.

### Prerequisites

- Docker Engine 24+
- Docker Compose v2+
- 2 GB RAM minimum

### Steps

```bash
git clone https://github.com/prismalens/prismalens
cd prismalens
cp .env.example .env
docker compose up -d
```

PrismaLens will be available at `http://localhost:3000`.

### Environment Variables

Configure PrismaLens by editing the `.env` file:

| Variable | Description | Default |
|----------|-------------|---------|
| `DATABASE_URL` | PostgreSQL connection string | `postgresql://...` |
| `AI_PROVIDER` | AI provider (`openai`, `anthropic`) | `openai` |
| `AI_API_KEY` | API key for the AI provider | — |

See the [settings guide](/guides/settings/) for the complete list.

## Health Check

Verify the installation:

```bash
curl http://localhost:3000/health
```

Expected response:

```json
{ "status": "ok" }
```
