This takes about ten minutes and needs no alert source. By the end you will
have run one investigation against real code and read its report.

## Before you start

- **macOS, Linux or WSL2.** Native Windows is not supported in 0.5.0.
- **Node.js 24** and **git 2.31 or newer**.
- **A coding agent** on your `PATH`, signed in. OpenCode is the one PrismaLens picks automatically: `npm i -g opencode-ai`, then sign it in. See [Coding agents](/coding-agents/) for the others.
- **A git repository** on this machine, or a git URL you can clone.

<Steps>

1. **Install**

   ```bash
   npm install -g prismalens
   ```

   This installs one command under two names, `prismalens` and `pl`.

2. **Check your machine**

   ```bash
   pl doctor
   ```

   Every hard check must pass. The lines that matter most:

   ```text
   ✔ Harness available: at least one harness is installed
   ✔ Auto-selected harness: opencode (auto)
   ✔ Harness ACP handshake: OpenCode: answers ACP
   ✔ All required checks passed.
   ```

   If no agent is found, `doctor` prints the install command for each one it
   knows.

3. **Start PrismaLens**

   ```bash
   pl up
   ```

   ```text
   ℹ Workspace: /home/you/.prismalens
   ℹ Logs: /home/you/.prismalens/logs
   ✔ PrismaLens is ready at http://localhost:3001
   ```

   The first start creates the database and its secrets in `~/.prismalens`.
   Leave this running.

4. **Create your account**

   Open [http://localhost:3001](http://localhost:3001). On **Welcome to
   PrismaLens**, fill in your email and a password, then **Create Account**.
   You are the owner, and nobody else can sign up.

5. **Point a service at its code**

   Open [http://localhost:3001/services](http://localhost:3001/services) and
   click **Add Service**. Give it a name, set **Repository** to a folder such as
   `~/code/payments` or a git URL, and click **Create Service**.

   The service shows what git found, such as `main at 3f2c9a1b04de`. If it shows
   an error instead, it is git's own message. Fix the path or your git access
   and save again. See [Services and their code](/guides/services/).

6. **Write the incident**

   Go to **Incidents** and click **Create Incident**. A title is the only
   required field. Describe the problem the way you would to a colleague, pick
   your service under **Service (optional)**, and click **Create Incident**.

   ```text
   Title: Checkout returns 500 after the 14:00 deploy
   Description: Error rate on POST /checkout went from 0.1% to 8%. Logs show
   "TypeError: cannot read properties of undefined (reading 'currency')".
   ```

7. **Run the investigation**

   On the incident, click **Investigate**, then open the **Investigation** tab.
   You watch the agent read files and run commands as it goes. Most runs take a
   few minutes, and none can run longer than 15.

   When it finishes, the report appears on the same tab: **Root Cause
   Analysis**, **Hypotheses**, **Ruled Out**, **Coverage** and **Next steps**.
   See [Reading the report](/guides/reports/).

</Steps>

<Aside type="note" title="If the run fails">
The Investigation tab shows **Investigation failed**, the error, the agent's
last events, and the path of the raw transcript, such as
`~/.prismalens/runs/<id>/transcript.jsonl`. The most common causes are an agent
that is not signed in and a repository git could not clone. `pl doctor` and the
service page show both.
</Aside>
