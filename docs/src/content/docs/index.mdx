---
title: What PrismaLens is
description: A self-hosted app that investigates an incident with the coding agent you already use, and keeps the evidence.
---

PrismaLens is an open-source app you run on your own machine with one command,
`pl up`. When something breaks, it opens an incident and hands it to a coding
agent you already have installed, such as OpenCode or Claude Code. The agent
reads a fresh copy of the service's code, works out what went wrong, and writes
a report. PrismaLens keeps the whole run: every command the agent ran, what it
found, and what it ruled out.

There is no PrismaLens account, no subscription and no model bill from us.
PrismaLens never calls a model. Your agent does, with your login.

## What a run looks like

1. An alert arrives from Prometheus, or you write the incident by hand.
2. PrismaLens takes a snapshot of the service's repository. Your own checkout is never the working directory.
3. Your coding agent investigates inside that snapshot. PrismaLens refuses its attempts to edit, delete or run a mutating command.
4. You watch the agent work on the incident page as it happens.
5. The report lists hypotheses in order, each with the evidence behind it, what was ruled out, and what to check next.

## When to use it instead of your agent

For a one-off question, ask your agent directly. PrismaLens is for everything
around the question. A webhook creates the incident, so the alert is already in
the brief when the agent starts. The run happens in a snapshot under a
read-only policy. And a week later the report, the evidence and the full event
stream are still on the incident.
