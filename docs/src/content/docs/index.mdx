## Get started

<CardGrid stagger>
  <Card title="Install the CLI" icon="laptop">
    Try it in minutes with `npx prismalens` — no account, no subscription. See [installation](/getting-started/installation/).
  </Card>
  <Card title="Run an investigation" icon="magnifier">
    Point it at a repo, pipe it a firing alert or ask a question, and get a report of evidence-linked hypotheses. Start at the [CLI overview](/cli/).
  </Card>
  <Card title="Bring your own model" icon="setting">
    Works with Ollama, OpenAI, Groq, any OpenAI-compatible endpoint, or your Claude Code install. See [providers & harnesses](/cli/providers/).
  </Card>
  <Card title="Contained by design" icon="approve-check">
    Investigations run read-only, optionally behind an enforced sandbox. See [sandboxing & permissions](/cli/sandboxing/).
  </Card>
</CardGrid>

:::note[What about the web UI?]
The self-hosted PrismaLens server — web UI, webhook alert intake, and team
features on top of the same engine — is in development and not released yet.
These docs cover the CLI, which is available on npm today.
:::
