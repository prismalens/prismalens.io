PrismaLens is an open-source app you run on your own machine with one command,
`pl up`. When something breaks, you open an incident, and PrismaLens hands it to
a coding agent you already have installed, such as OpenCode or Claude Code. The
agent reads a fresh copy of the service's code, works out what went wrong, and
writes a report. PrismaLens keeps the whole run: every command the agent ran,
what it found, and what it ruled out.

There is no PrismaLens account, no subscription and no model bill from us.
PrismaLens never calls a model itself. Your agent does, with your login.

## What a run looks like

1. An alert arrives from Prometheus, or you write the incident by hand.
2. PrismaLens takes a snapshot of the service's repository, so your own checkout is never touched.
3. Your coding agent investigates inside that snapshot. PrismaLens refuses its attempts to edit, delete or run a mutating command.
4. You watch the agent work on the incident page, live.
5. The report lists hypotheses in order, each with the evidence behind it, what was ruled out, and what to check next.

## Why not just ask the agent yourself?

You can, and for a one-off question you should. PrismaLens is for the part
around the question:

- **It starts from the alert.** A webhook creates the incident, and the alert
  details are already in the brief when the agent starts.
- **It keeps the agent's hands off.** The run happens in a snapshot, and
  PrismaLens answers every permission request with a read-only policy.
- **It gives you a record, not a chat.** A week later the report, the evidence
  and the full event stream are still on the incident.
