## Prerequisites

Start here: [GitHub setup page](https://github.com/settings/tokens?type=beta)

1. Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. Click 'Generate new token'
3. Set a descriptive name like 'PrismaLens'
4. Set expiration (recommend 90 days, rotate regularly)
5. Under 'Repository access', select the repositories PrismaLens should access
6. Under 'Permissions', grant 'Contents: Read-only' and 'Metadata: Read-only'
7. Click 'Generate token' and copy the token immediately (it won't be shown again)

## Tips

- Fine-grained PATs are recommended over classic tokens for better security scoping
- Tokens expire — set a calendar reminder to rotate before expiry
- Classic tokens (ghp_...) also work but grant broader access than necessary
