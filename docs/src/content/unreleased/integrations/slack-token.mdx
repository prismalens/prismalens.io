## Prerequisites

Start here: [Slack setup page](https://api.slack.com/apps)

1. Go to api.slack.com/apps and click 'Create New App'
2. Choose 'From scratch' and name it 'PrismaLens'
3. Go to 'OAuth & Permissions' and add Bot Token Scopes: chat:write
4. Click 'Install to Workspace' and authorize
5. Copy the 'Bot User OAuth Token' (starts with xoxb-)
