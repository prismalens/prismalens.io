# Security Policy

This repository hosts the PrismaLens marketing site and documentation — static
Astro sites with no backend, no user accounts, and no stored data. Security
issues in the **PrismaLens product** (the CLI/engine) belong in the main
repository's policy:
https://github.com/prismalens/prismalens/blob/main/SECURITY.md

## Reporting a vulnerability in this repo

Relevant here: dependency vulnerabilities in the site build chain, content
injection in a deployed page, or issues with the Cloudflare Pages deployment.

**Please do not report security issues through public GitHub issues.**

Use GitHub's private vulnerability reporting:

- Go to this repository's **Security** tab and choose
  **[Report a vulnerability](https://github.com/prismalens/prismalens.io/security/advisories/new)**.

You should get an initial response within a few days. Please include steps to
reproduce and the affected page/URL where applicable.
